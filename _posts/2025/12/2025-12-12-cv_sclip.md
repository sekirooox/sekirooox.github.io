# SCLIP
Abstract. Recent advances in contrastive language-image pretraining (CLIP) have demonstrated strong capabilities in zero-shot classification by aligning visual and textual features at an image level. However, in dense prediction tasks, CLIP often struggles to localize visual features within an image and fails to attain favorable pixel-level segmentation results. In this work, we investigate in CLIP’s spatial reasoning mechanism and identify that its failure of dense prediction is caused by a location misalignment issue in the self-attention process. Based on this observation, we propose a training-free adaptation approach for CLIP’s semantic segmentation, which only introduces a very simple modification to CLIP but can effectively address the issue of location misalignment. Specifically, we reform the self-attention mechanism with leveraging query-to-query and key-to-key similarity to determine attention scores. Remarkably, this minimal modification to CLIP significantly enhances its capability in dense prediction, improving the original CLIP’s 14.1% average zero-shot mIoU over eight semantic segmentation benchmarks to 38.2%, and outperforming the existing SoTA’s 33.9% by a large margin. Code is available at https://github.com/wangf3014/SCLIP.

抽象的。对比语言图像预训练（CLIP）的最新进展通过在图像级别对齐视觉和文本特征，展示了零样本分类的强大能力。然而，在密集的预测任务中，CLIP 通常难以定位图像中的视觉特征，并且无法获得良好的像素级分割结果。在这项工作中，我们研究了 CLIP 的空间推理机制，并发现其密集预测的失败是由自注意力过程中的位置错位问题引起的。基于这一观察，我们提出了一种针对 CLIP 语义分割的免训练自适应方法，该方法仅对 CLIP 进行了非常简单的修改，但可以有效解决位置错位的问题。具体来说，我们利用查询到查询和键到键的相似性来确定注意力分数，从而改革自注意力机制。值得注意的是，对 CLIP 的这种最小修改显着增强了其密集预测的能力，将原始 CLIP 在八个语义分割基准上的平均零样本 mIoU 提高到了 38.2%，从 14.1% 提高到了 38.2%，并且大大超过了现有 SoTA 的 33.9%。代码可在 https://github.com/wangf3014/SCLIP 获取。

# 动机
CLIP学习到的局部特征是空间不变的，意味着不同位置学习到的token，注意力图非常相似，这使得CLIP趋向整体表达。
但是语义分割需要空间协变的特征，意味着不同位置的token，学习到的注意力图应该明显不一样，局部特征可区分。
Mask CLIP使用单位矩阵，强迫token与自己交互，聚焦低级推理。

# 消融实验
作者把注意力**限制在某一区域内(调节温度)**并**设置窗口大小(局部注意力)**。
这项消融研究表明，**仅仅关注局部视觉特征并不能有效地将弱监督的预训练模型**（例如 CLIP）转换为语义分割挑战。相比之下，我们的方法结合了相关的自注意力机制，**考虑了局部特征和总体语义上下文之间的关系**，被证明更适合跨不同尺度的视觉推理任务。
作者发现CLIP中**间层的注意力矩阵替换最后一层也可以提高性能**。

## 0. 摘要翻译（原文→中文）

论文指出：CLIP 在图像级对齐很强，但做语义分割这类**密集预测**时经常**定位失败**。作者分析认为失败源自自注意力中的**位置不对齐（location misalignment）**。为此提出一个**训练-free**的适配方法：把自注意力的“Q·K”打分改成由**query-to-query 与 key-to-key 的相似度**来决定注意力分数（本质是用 token 间相关性来做 attention）。这一极小改动显著提升 CLIP 的密集预测能力：8 个分割基准上，CLIP 平均 zero-shot mIoU 从 **14.1%→38.2%**，并超过当时 SOTA **33.9%**。代码开源在 GitHub。

## 1. 方法动机

### a) 为什么提出？

作者观察到：CLIP 不是“不知道图里有什么”，而是“**知道但放错位置**”。定性例子里，CLIP 能识别类别（如 flamingo、水、陆地），但会把水分到火烈鸟位置、把火烈鸟分到水里，体现为局部特征与空间位置的错配。

### b) 现有方法痛点/不足

* **直接用 patch 特征对齐文本**几乎不可用：例如 ViT-B/16 输入 224×224 只得到 14×14 dense feature，直接做像素/patch 分类在 ADE20k/COCO-Stuff 上 mIoU 很低（文中给出 3.1%、5.7% 量级）。
* **强行“只看自己”(identity attention)**（如 MaskCLIP 在最后一层让 token 只 attend 自己）能提升定位，但会**过度聚焦低级局部纹理**，导致输出噪声、块状不连贯。
* 许多方法依赖 **PAMR / DenseCRF** 等后处理来“抹平”，但作者认为这会掩盖模型本身的分割推理能力，而且计算重。

### c) 研究假设/直觉

CLIP 的自注意力学到的是**空间不变（spatial-invariant）**的特征：不同位置 token 的 attention pattern 很相似，趋向全局/整体表示；而语义分割需要**空间协变（spatial-covariant）**：位置不同，表示应随位置变化，且同一语义区域内部应相互支持。作者因此把矛头指向：**自注意力的打分方式导致位置不对齐**。

## 2. 方法设计（非常细）

### a) Pipeline：输入→处理→输出（逐步）

以 CLIP ViT-B/16 视觉编码器为例（作者主要讨论 Transformer 图像编码器）：

**Step 1：输入与token化**

* 输入图像 (3\times w\times h)，切成 (p\times p) patch。
* 得到 token 序列 (X={x_{cls},x_1,\dots,x_l}\in\mathbb{R}^{(l+1)\times d})，其中 (l=wh/p^2)，每个 token 维度 (d)。

**Step 2：定位问题归因：自注意力的“QK打分”导致空间不变**

* 传统 self-attn：
  [
  Attn=\text{Softmax}(XW_qW_k^TX^T/\sqrt{d})
  ]
  其训练目标偏图像级对齐，会鼓励“全局/整体”聚合，从而让不同位置的 attention map 变得相似（空间不变）。

**Step 3：提出 CSA（Correlative Self-Attention）用“相关性”重写注意力**

* 核心替换：不用 (Q\cdot K)，而是让 attention 由**同类空间token之间的相关性**决定：
  [
  Attn=\text{Softmax}(XW_rW_r^TX^T/\tau)
  ]
  这里 (W_r\in\mathbb{R}^{d\times d})，(\tau) 默认取 (\sqrt d)。
* 直觉：若两个位置的 token 语义相似（投影后余弦/相关性高），它们就互相给高 attention；同时对角线（自己对自己）天然最大→定位增强。
* 与 MaskCLIP 的差异：MaskCLIP 是**硬约束**“只看自己”(window=1)，CSA 是**软约束**“看自己 + 看语义相似的区域”，所以更平滑、更鲁棒。

**Step 4：SCLIP 如何“无训练”落地到 CLIP 上**
作者把 CLIP 视觉编码器的**最后一个 Transformer block**视为“任务解码层”，只在这一层做改动，其它层不动。
在该最后层里：

* 用 CSA 替换原 self-attn。
* 关键：不新训 (W_r)，而是直接复用 CLIP 里原本的 (W_q) 和 (W_k)，做一个 ensemble：
  [
  Attn = \text{Softmax}(XW_qW_q^TX^T/\tau)+\text{Softmax}(XW_kW_k^TX^T/\tau)
  ]
  这就是摘要里说的 query-to-query 和 key-to-key 相似度。

**Step 5：输出分割**

* 仍然用 CLIP 文本编码器得到类别文本 embedding；
* 用视觉端输出的 dense feature 与文本 embedding 对齐做分类，得到像素/patch 的类别分布（论文在实验设置里明确基线就是这么做的，只是 SCLIP 的 dense feature 更“对齐位置”）。

> 重要立场：作者强调他们**默认不使用** PAMR/DenseCRF 等重后处理，认为空间连续性应由模型结构本身学出来；并声称 SCLIP 输出已足够平滑。

### b) 模块功能与协同

* **CLIP视觉编码器（大部分层）**：保留其强语义表征能力（知道是什么）。
* **最后一层 CSA（关键改动点）**：重新组织空间信息，让 token 表征变得空间协变（知道在哪里），并利用“语义相似区域互相支持”减少噪声。
* **文本编码器**：提供开放词表类别原型；无需训练。

### c) 公式/算法的通俗解释

* 传统 self-attn 用两次投影得到 Q、K，再做 (QK^T)。作者认为这套机制在 CLIP 的图像级预训练下会偏向“大家都看差不多的全局东西”，导致位置不敏感。
* CSA 用“同一套投影后的向量之间的相似度”来打分，本质是“**以语义相关性为纽带做聚合**”：一个位置的 token 会把信息从“像我”的区域聚过来，于是同一物体内部互相强化、边界更清晰（论文图4展示了注意力图更有对象边界、且不同点的 attention map 更不同）。

## 3. 与其他方法对比

### a) 本质不同

* **MaskCLIP**：把最后层 attention 近似变成 identity（只看自己），强定位但易噪声。
* **TCL / GroupViT / ReCo 等**：通常引入额外结构、训练或后处理/聚类等机制；而 SCLIP 主张“最小结构改动 + 不训练”。
* **SCLIP**：用“相关性注意力”让 token 同时具备定位与语义一致性，且只动最后一层。

### b) 创新点与贡献度（明确）

1. **问题定位**：指出 CLIP 分割差的核心是 self-attn 导致的 **location misalignment / spatial-invariant**。
2. **CSA 机制**：用 (XW_rW_r^TX^T) 的相关性形式替代 QK 打分，提升空间协变。
3. **训练-free 落地**：复用 CLIP 的 (W_q,W_k) 作为投影（式3），只替换最后 block，自称“无额外参数/无微调”。

### c) 更适用的场景

* **零样本 / 开放词表语义分割**，希望尽量不训练、不引入额外模型时（“拿一个现成 CLIP 就想分割”）。
* 对后处理成本敏感的场景：作者刻意弱化 PAMR 等重后处理。

### d) 表格：方法对比（优缺点/改进点）

| 方法               | 核心思路                           |       需要训练？ | 优点                  | 缺点/风险                          | 相对改进点（对SCLIP）         |
| ---------------- | ------------------------------ | ----------: | ------------------- | ------------------------------ | --------------------- |
| CLIP 直接patch对齐文本 | 直接用 dense feature 做分类          |           否 | 最简单                 | 定位错、mIoU极低（平均14.1）             | SCLIP 改注意力解决定位错       |
| MaskCLIP         | 最后一层近似 identity attention（强定位） |           否 | mIoU 提升明显（avg 30.3） | 易噪声、不连贯                        | SCLIP “看自己+看相似区域”更平滑  |
| TCL              | 学习生成文本引导mask等（论文列为强基线）         | 通常是（方法本身训练） | avg 33.9            | 复杂度/训练成本更高                     | SCLIP 不训练且更高 avg 38.2 |
| GroupViT         | 引入group token并预训练              |           是 | 结构化分组语义             | 依赖预训练/训练                       | SCLIP 只改CLIP最后层即可     |

## 4. 实验表现与优势

### a) 如何验证有效性（实验设计）

* 评测 8 个语义分割基准：VOC、PASCAL Context、Cityscapes、ADE20k、COCO-Stuff、COCO-Object 等。
* 对比强基线：MaskCLIP、GroupViT、ReCo、TCL、CLIP-Surgery 等；并强调默认不使用重后处理 PAMR（但也给了带 PAMR 的结果）。

### b) 关键指标与代表性数据

主表（Table 1）给出：SCLIP 在 8 数据集平均 **38.2**，CLIP **14.1**，TCL **33.9**，MaskCLIP **30.3**。
并且在多个数据集上领先明显（例如 PASCAL Context59/60、Cityscapes、ADE20k 等）。

### c) 哪些场景优势最明显（证据）

* **高分辨率/复杂场景**：定性图中 SCLIP 的 mask 更干净、边界更清晰，尤其对高分辨率野外图像表现更稳定（Fig.1 的描述）。
* **类别较少数据集（VOC）**：附录可视化表明能分出细小结构（羊腿、盆栽枝条等），MaskCLIP 更粗糙或把前景和背景糊在一起。

### d) 局限性/不足（论文承认或隐含）

* **仍是全局注意力计算**：CSA 形式没有把复杂度降到局部注意力那种窗口级别（隐含推理开销仍不低，作者主要通过 sliding-window 控制）。
* **改动集中在最后一层的“解码层”假设**：作者依据对不同层注意力模式的观察，把最后 block 当 decoder（这是一种经验设计，换 backbone/层数可能需重新验证）。
* **与后处理的关系**：虽然带 PAMR 都能涨，但作者不建议默认用（意味着若你追极致指标，后处理/超参仍会影响结果）。

## 5. 学习与应用（复现/迁移建议）

### a) 是否开源？复现关键步骤

* 开源：摘要里给出代码仓库地址。
  复现最关键就两件事：

1. 在 **CLIP ViT 视觉编码器最后一个 transformer block**，把原 self-attn 替换成 CSA；
2. attention 打分用式(3)：分别用 (W_q) 与 (W_k) 做 (XW W^T X^T) 并 softmax 后相加（训练-free）。

### b) 超参数/预处理/实现细节（很落地）

* **温度 (\tau)**：默认 (\sqrt d)（与标准 self-attn 一致）。
* **投影矩阵选择**：论文做了消融，说明 CSA 对 (W_r) 不敏感；随机矩阵、identity、单独 (W_q)/(W_k) 都能跑，学习 (W_r) 只带来小幅提升。
* **推理的滑窗设置很关键**：作者默认把图短边 resize 到 336，用 224×224 window、stride 112 做 sliding inference；这比一些 prior work 的 448 设置更贴合 CLIP 原始输入尺寸，且 stride 更小输出更平滑。
* **不要默认开 PAMR**：作者认为重后处理会掩盖模型能力且计算重（但你做对比论文时可以同时报告带/不带）。

### c) 能否迁移到其他任务？怎么迁移？

可以，迁移逻辑是：**凡是需要“保留 CLIP 语义、增强空间定位”的密集任务**，都可能受益，例如：

* 开放词表的**实例/全景分割**：把“最后层更空间协变”的 dense feature 接到你的 mask/region 预测头上；
* **开放词表检测**：用 CSA 改善候选区域的空间一致性，再做文本对齐分类；
* 甚至非 VL 的密集任务：把 CSA 当作一种“让 token 更位置敏感”的解码注意力模块。
  但要注意：论文主要验证在 CLIP ViT 结构、且只改最后 block 的设定；换成多尺度 backbone 或需要强边界细节的任务，可能要把 CSA 放到“多层/多尺度”或配合轻量边界细化。

## 6. 总结

### a) 20字内一句话核心思想

**用相关性注意力修正CLIP的定位错配。** 

### b) 速记版 pipeline（3–5步、避免论文术语、直白自明）

1. 把图像切成小块并提取每块特征
2. 在最后一层，把“用两路向量点积算权重”改成“用特征相似度算权重”
3. 让每个位置主要聚合自己和相似区域的信息
4. 用文本类别向量对每个位置做匹配得到类别图
5. 滑窗拼接得到整图分割结果
