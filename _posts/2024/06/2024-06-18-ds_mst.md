# 最小生成树
+ 极小连通子图
+ **只有n-1条边**：该性质可以用于判断是否存在最短生成树。
## prim算法
### 核心思想：贪心
+ 树的问题：就建立v-1条边
+ 最小的问题：每次只选择距离生成树最近的一条边，达到**局部最优**，最终贪心出来**全局最优**
### 基本思路
+ 定义一个dist数组：**表示与最小生成树的距离**
+ 选点
+ 标记
+ 更新：因为dist表示与最小生成树的距离，**所以当前遍历节点的dist[i]就完全没用**，**只比较保留grid[i][j]就行**！
### 朴素实现：$O(V^2)$
+ **不存在生成树的情况：**图未联通。假设第一次遍历的永远是节点1(手动设置dist[1]=0)，那么如果存在选完点后，**记录最小dist的`tmp=MAX_VALUE`，说明图不连通**。
+ 最短生成树距离：记录dist[2~n]即可，**dist[1]为无效值0**。

```cpp
int n, m;
int g[509][509],dist[509],visited[509],res=0;
void prim() {
	for (int i = 1; i <= n; i++) {
		int idx = -1 ,tmp = INT_MAX;
		for (int j = 1; j <= n; j++) {
			if (!visited[j] && dist[j] < tmp) {
				tmp = dist[j];
				idx = j;
			}
		}
		if (i == 1) {
			dist[idx] = 0;
		}
		if (i> 1 && tmp == MAX_VALUE) {
			cout << "impossible";
			return;
		}
		if (i > 1) {
			res += dist[idx];
		}
		visited[idx] = 1;
		for (int j = 1; j <= n; j++) {
			if (!visited[j]) {
				dist[j] = min(dist[j], g[idx][j]);
			}
		}
	}
	cout << res;
}
```

## Kruskal算法：$O(mlogm)$
### 核心思想：贪心
+ 直接了当的贪心：**直接加入最小权值的边**
+ 使用并查集判断实现**同一集合判定**(等价于**图中的连通性判定**)和合并。
### 实现
+ 排序最小边
+ 加入边，验证是否有环
+ **判定生成树的存在性**：定义`cnt`表示记录的边数，**生成树的边数一定为n-1**，如果不等于该值，则一定不存在最小生成树。

```cpp
int n, m,ans,cnt;
int fa[100009];
int find(int x) {
	if (fa[x] == x)return x;
	else return fa[x] = find(fa[x]);
}

typedef struct node {
	int x, y, w;
};
node edges[200009];
void ks() {
	for (int i = 1; i <= n; i++)fa[i] = i;
	sort(edges + 1, edges + m + 1, [&](const node& a, const node& b) {return a.w < b.w; });
	for (int i = 1; i <= m; i++) {
		int x = edges[i].x, y = edges[i].y, w = edges[i].w;
		int fx = find(x), fy = find(y);
		if (fx != fy) {
			ans += w;
			cnt++;
			fa[fx] = fy;
		}
	}
	if (cnt != n - 1) {
		cout << "impossible";
	}
	else cout << ans;
}
```
