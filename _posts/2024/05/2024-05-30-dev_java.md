## 抽象类和抽象方法
+ ### 抽象类
  + 关键字 **abstract**
  + `public abstract class classname{body}`Java中的抽象类
  + `virtual void method()=0`C++中的抽象类(纯虚类)
  + `new abstractclass()`无法实例化
  + `super()`**仍然有构造函数**
  + `ArrayList<abstractclass>list`**抽象类可以作为数据类型**
  + 可以不包含抽象方法
+ ### 抽象方法
  + 只能声明/定义于抽象类中,**关键词abstract**
  + `public abstract void method(){}`
  abstract关键字+函数体为空
  + 子类是抽象类：继续包含父类的抽象方法
  **类似于C++中子类不覆盖父类的抽象方法,子类也为抽象类**
  + 子类不是抽象类:必须覆盖父类的抽象方法
  + **C++中子类可以不覆盖父类的抽象方法,但子类会变为抽象类**
+ ### 接口类interface
  + `public interface interfaceName`与类的声明一致,关键字interface
  + 无法实例化
  + 仅含有常量和抽象方法
  + **省略修饰符**`public static final int K`等价于`K`
  + Java中,很多非接口类继承了接口类
  这点**类似于C++中的运算符重载**
  Java**没有运算符重载**,使用继承接口类解决问题
  + ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/631e5519b609968a1082bbf226b0c585.png#pic_center){: referrerpolicy="no-referrer" }
继承了comparable函数接口的类
  + `public object clone(){//body}`Java的拷贝构造函数
  + **Object继承了Cloneable interface**,实现数据的拷贝
+ ### 接口类和抽象类的区别
  类|抽象类|接口类
  ---|---|---
  数据类型|**抽象类可以有自己的数据和非抽象方法**|接口类只含有常量和抽象类
  用途|继承关系明显,或者**需要继承父类的元素和非抽象方法**|继承关系淡,**只需要重写其中的抽象类**
  相同点|不可实例化|不可实例化

  + 修饰变量**放前面**

            `final class constant{}`
  + 防止重写 `void method() final{}`


+ ### 构造与析构顺序
  + 与C++一致
  + 构造先父后子，析构先子后父
  

+ ### 重写Override
  + 子类默认重写父类的同名函数
  + static和private的方法不能被override
  + #### Java与C++的区别
    +  Java|C++
        ---|---
        Java**直接**重写|C++的父类函数**必须声明为virtual**| 


+ ### Object类
  + 所有子类默认继承object
  + `object.toString()`
    指出 classname@memory_address


+ ### 动态绑定
    + 运行时确定类型
    + **参数类型决定可见成员**
    + #### Java与C++的区别
     Java|C++
     ---|---
    所有类为引用,**自动进行动态绑定**|参数必须为引用或者指针
    Java接受子->父的转换|C++接受子->父的转换
    Java允许**强制**父->子转换|C++允许**强制**父->子转换
    + `myObject instanceof Circle` Java检验动态类型
        运算符，检验myObject对象是否是circle类
    + `typeid(*b1)` C++检验动态类型
        运算符,检验b1(**指针要解引用**)的动态类型

## 异常处理
+ 与C++基本一致
+ try与catch语句
  ```java
    try{
    //throw exception
    throw new Exception("exception name");//一般用new+匿名变量
    }
    catch(Exception r){
    //handle exception
    }
  ```
+ ### Exception的种类
  ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/14402b7c834e78dc4a3ce9c7855732f5.png#pic_center){: referrerpolicy="no-referrer" }


  + #### Unchecked Exceptions
      ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/f2fe011e6ad9fe6b2bee0f3e8ae4988d.png#pic_center){: referrerpolicy="no-referrer" }



    + Unchecked Exceptions一般是严重的错误
    + **不需要声明**throw exceptions
  + #### Checked Exceptions
    + **需要声明**throw exceptions
    + `method()throws Exceptions{//body}`抛出的错误可以具体为`throws IOException`,但是我个人一般只会写Exceptions,因为他们由Exceptions继承而来
    + 
+ ### 捕获Exceptions
  + 与C++原理基本一致
  + **栈展开** 
 	本层找catch,没有则递归地找上一层匹配的catch,直到找到匹配的catch语句或者终止整个程序
+ ### rethrow和finally语句
  + `catch{throw ex;}`在catch语句中重新throw,将Exceptions交给上一层函数处理
  + C++没有finally语句
  + finally是无论如何都要执行的语句
```java
  try{
    throw new Exceptions();//扔出异常
    }
  catch(Exceptions ex){
        //无论是否处理成功,catch后面的语句都不会执行了
    }
  finally{
    //但finally是一定会执行的语句
    }
```
```java
try{
return ;
//try中return,程序终止,但finally语句仍然执行
}
catch(){
}
finally{
//statement
}
```
