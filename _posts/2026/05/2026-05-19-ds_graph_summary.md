## 判断是否有环
### DFS：三色判定法；`相当于记忆化搜索`，记录已经搜索的无环路径为2，有环为1，避免冲突；
+ **为什么需要三种颜色？**：使用DFS从一个节点开始一一遍历可以判断是否存在b环，但是效率比较低，太多重复遍历的路径。
+ 标记原理：遍历过且无环的节点为2，遍历过但有环路径上的节点为1。**遇到标记为2的路径，知道沿着该路径一定无环**；如果为1，b。
+ dfs判定环看是否有重复遍历。
+ 但有重复遍历，不一定有环。

```cpp
class Solution {
public:
    vector<int>visited=vector<int>(2009,0);
    bool dfs(int x,const vector<vector<int>>&g){
        if(visited[x]){
            return visited[x]==2;
        }
        visited[x]=1;// 相当于默认遍历过且默认有环
        for(auto item:g[x]){
            if(!dfs(item,g)){// 如果路径中有环，则停止刚更新
                return false;
            }
        }
        visited[x]=2;// 记忆化数组改为2，表示无环路径
        return true;
    }
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>>g(2009);
        for(auto edge:prerequisites){
            g[edge[1]].push_back(edge[0]);
        }
        int n = numCourses;
        for(int i=0;i<n;i++){
            if(visited[i]==0){
                if(!dfs(i,g))return false;
            }
        }
        return true;
    }
};
```

## 判定是否存在负环
### Bellman算法：更新次数大于n-1
+ 额外增加一次循环(表示长度为n)的路径，如果更新则存在负环。

### SPFA算法：更新次数大于n-1
+ **使用`count`记录更新次数。**
+ 注意：存在多个连通块，因此必须让每个节点都入对列，保证**检查每一个连通块的负环情况**。

### 常见技巧：1.状态转字符串 2.二维索引转一维索引$(i,j)=n\cdot i+j$，简化判定合法逻辑

```cpp
    int bfs(queue<string>&q1,unordered_map<string,int>&dist1,unordered_map<string,int>&dist2,const int&n,const int&m){
        string cur = q1.front();
        int size = cur.size();
        q1.pop();
        for(int i=0;i<size;i++){
            string nxt(cur.begin(),cur.end());
            if(nxt[i]=='0')nxt[i]='1';
            else nxt[i]='0';
            int x=i/m,y=i%m;
            for(int j=0;j<4;j++){
                int nxt_x = x+dir[j][0];
                int nxt_y = y+dir[j][1];
                if(nxt_x>=0&&nxt_x<n&&nxt_y>=0&&nxt_y<m){
                    int nxt_idx = nxt_x*m+nxt_y;
                    if(nxt[nxt_idx]=='0')nxt[nxt_idx]='1';
                    else nxt[nxt_idx]='0';
                    // nxt[nxt_idx]=!nxt[nxt_idx];// 0->1,1->0
                }
            }
            if(dist2.count(nxt)){
                return dist1[cur]+dist2[nxt]+1;
            }
            if(!dist1.count(nxt)){
                q1.push(nxt);
                dist1[nxt]=dist1[cur]+1;
            }
        }
        return -1;
    }
```
